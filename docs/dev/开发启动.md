# 开发启动说明

本机开发环境依赖中间件启动方式汇总（原 `scheduler-JAVA/dev-start.txt` 整理）。

## RocketMQ

**NameServer**

```bat
mqnamesrv.cmd
```

**Broker（基础配置，自动建主题）**

```bat
mqbroker.cmd -n 127.0.0.1:9876 autoCreateTopicEnable=true
```

## MinIO

```bat
D:\Project\Scheduler\minio.exe server D:\minio_data --console-address ":9001"
```

- 服务端口：`9000`（API）
- 控制台端口：`9001`
- 默认账号：`changeme / changeme`

## 中间件一览

| 中间件 | 默认地址 | 用途 |
|---|---|---|
| MySQL | `localhost:3306` | 任务/运行/脚本等持久化 |
| Redis | `localhost:6379` | Worker 心跳、负载、路由游标 |
| RocketMQ | `127.0.0.1:9876` | 任务派发 / 结果回流 / 控制指令 |
| MinIO | `localhost:9000` | 脚本文件、任务日志存储 |
