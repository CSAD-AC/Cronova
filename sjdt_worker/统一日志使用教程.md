# 统一日志系统使用教程

## 概述

本教程指导您如何在项目各模块中使用统一日志系统，实现彩色控制台输出和统一的日志格式。

## 使用方法

### 统一导入方式

在任何Python文件中使用以下导入方式：

```python
from utils import logger
```

### 五种日志等级使用方法

```python
# 1. DEBUG 级别 - 调试信息（青色）
logger.debug("调试信息：变量值为 %s", variable_value)

# 2. INFO 级别 - 一般信息（绿色）
logger.info("系统启动完成，端口：%d", 8080)

# 3. WARNING 级别 - 警告信息（黄色）
logger.warning("配置文件不存在，使用默认配置")

# 4. ERROR 级别 - 错误信息（红色）
logger.error("数据库连接失败：%s", error_message)

# 5. CRITICAL 级别 - 严重错误（洋红色+粗体）
logger.critical("系统内存不足，程序即将退出")
```

## 快速使用示例

### 基础示例
```python
from utils import logger

def my_function():
    logger.info("函数开始执行")
    
    try:
        # 业务逻辑
        result = process_data()
        logger.info("数据处理完成，结果：%s", result)
    except Exception as e:
        logger.error("处理数据时出错：%s", str(e))
        raise
    
    logger.info("函数执行完成")
```

### 参数格式化
```python
# 支持多种格式化方式
logger.info("用户 %s 登录成功", username)
logger.info("处理了 %d 个任务，耗时 %f 秒", count, duration)
logger.info("文件路径: %s, 大小: %d bytes", file_path, file_size)
```

### 异常处理
```python
try:
    risky_operation()
except Exception as e:
    logger.exception("操作失败，详细错误：%s", str(e))
    # exception() 方法会自动包含堆栈跟踪信息
```

## 特性说明

1. **彩色输出**：不同级别日志在控制台中显示不同颜色
2. **统一格式**：所有日志遵循统一格式（时间 | 级别 | 位置 - 消息）
3. **位置跟踪**：自动显示调用文件名、函数名和行号
4. **单例模式**：整个应用使用同一个日志实例，避免重复初始化
5. **向后兼容**：支持原有的日志调用方式

## 日志格式示例

```
2026-02-04 14:25:27 | INFO     | module.py:function:123 - 这是一条信息消息
2026-02-04 14:25:27 | WARNING  | module.py:function:124 - 这是一条警告消息
2026-02-04 14:25:27 | ERROR    | module.py:function:125 - 这是一条错误消息
```

## 迁移指南

### 原有代码
```python
# 旧方式（仍可使用）
from app.utils.log_utils import get_logger
logger = get_logger()
logger.info("消息")
```

### 统一方式（推荐）
```python
# 新方式（统一使用）
from utils import logger
logger.info("消息")
```

## 注意事项

1. **导入路径**：统一使用 `from utils import logger`
2. **颜色支持**：在支持的终端中自动启用彩色输出
3. **性能优化**：使用单例模式，性能优异
4. **线程安全**：多线程环境安全使用
